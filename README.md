# 秋招投递管理器

一个可以直接在浏览器使用的秋招投递管理网页。

## 功能

- 新增、抽屉编辑、删除投递记录，并在表格中直接修改阶段与公司类型
- 记录公司、岗位、公司类型（互联网/央国企）、城市、投递日期、当前阶段、安排事项和备注
- 类型计数筛选、批量分类、搜索、阶段筛选、排序、彩色阶段分布和未来安排
- 浏览器本地自动保存、历史快照、导入与导出备份
- 可通过独立 Cloudflare Worker 手动单向同步到飞书多维表格
- 直接粘贴图片或一次选择最多 20 张岗位截图，在浏览器本地增强、识别、校对并自动去重后加入岗位库，不上传图片
- 使用“秋招一键收录”浏览器插件识别已打开的招聘投递页面，并在保存前人工确认结果
- 支持安装到 iPhone、Android 手机桌面，像普通 App 一样全屏打开

## 手机 App（PWA）

这个项目现在是可安装的网页 App，不需要上架应用商店，也不需要额外安装包。手机必须通过 GitHub Pages 的 `https://` 网页地址打开，直接打开本地 `file://` 文件不能完成安装。

- iPhone：用 Safari 打开网页，点击“分享” → “添加到主屏幕”。
- Android：用 Chrome 打开网页，点击网页里的“安装到手机”，或浏览器菜单中的“安装应用/添加到主屏幕”。
- 以后更新 GitHub Pages 后，手机 App 会自动读取新版本；投递记录仍保存在当前手机的浏览器本地，不会因为更新网页代码而被覆盖。

电脑和手机是两份独立的本地数据。第一次换到手机时，请先在电脑点击“导出数据”，再在手机网页的“数据安全”中导入该 JSON 备份。

## 浏览器插件

[下载秋招一键收录插件 1.5.0](./秋招一键收录插件.zip)

下载后先解压，在 Chrome 的 `chrome://extensions/` 页面开启开发者模式，点击“加载已解压的扩展程序”，选择解压后的插件文件夹，并在插件详情中开启“允许访问文件网址”。

不同招聘网站的页面结构会变化，自动识别结果必须在保存前检查；页面没有明确显示的城市或日期会保持空白。

## 飞书多维表格同步

同步采用“本地管理器 → 飞书”的单向模式，以记录 ID 新增或更新飞书记录，不会删除飞书记录，也不会把飞书修改写回本机。飞书密钥必须保存在 Cloudflare Worker Secret 中，不得写入网页或提交到仓库。

完整部署和授权步骤见 [worker/README.md](./worker/README.md)。未配置 Worker 时，管理器的所有本地功能仍可正常使用。

## 数据说明

投递记录默认保存在每位使用者自己的浏览器中，不会提交到这个 GitHub 仓库。只有点击“同步到飞书”时，结构化文字记录才会发送到你配置的 Worker 和飞书多维表格；截图和 OCR 原图不会上传。

从本地文件版切换到 GitHub 网页版时，浏览器会把它们视为两个不同网站。请先在旧版本点击“导出数据”，再在网页版的“数据安全”中导入备份文件。

## 本地使用

下载整个仓库后双击 `index.html`。`index.html` 与 `ocr` 文件夹必须保持在同一目录中。

## 发布到 GitHub Pages

仓库根目录需保留 `index.html`、`manifest.webmanifest`、`service-worker.js`、`icons` 和 `ocr`。在仓库 Settings → Pages 中选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后等待 GitHub 生成 HTTPS 访问地址。
